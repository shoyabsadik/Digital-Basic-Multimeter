# Digital Basic Multimeter

A compact and rechargeable digital multimeter capable of measuring voltage and current while also providing continuity and buzzer testing functions.

This project is designed using readily available components and can be used as a basic educational multimeter for electronics learning and laboratory applications.

## Features

✅ DC Voltage Measurement

✅ DC Current Measurement

✅ Continuity Testing

✅ Buzzer Mode

✅ Rechargeable Battery Powered

✅ Portable Design

✅ Mode Selection using Slider Switch

## Working Principle

The multimeter uses a digital voltage-current display module to measure electrical parameters.

### Voltage Mode

- The slider switch is set to Voltage Mode.
- Input voltage is connected through the measurement terminals.
- The display module shows the measured voltage.

### Current Mode

- The slider switch is switched to Current Mode.
- Current flows through the meter's internal current sensing circuit.
- The display displays the measured current value.

### Continuity Mode

- The continuity circuit checks whether two points are electrically connected.
- If continuity is detected, the buzzer produces an audible sound.

### Buzzer Test Mode

- Used for quick wire and connection testing.
- An LED indicator and buzzer provide visual and audio feedback.
